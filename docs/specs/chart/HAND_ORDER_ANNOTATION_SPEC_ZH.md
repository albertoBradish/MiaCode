# 手序标注语法与语义

状态：语法契约于 2026-10-21 确认。截至 2026-10-22，Wifi Split/Single 的解析、手动编辑、保存与变换、共享预览及视频导出已端到端实现，并通过 MiaCode Release 构建、19 项相关 CTest 及真实离屏 QSG/UI 验收。验证使用合成谱面，主 GUI 和真实谱面仍未验证。

## 作用范围

手序是附着于一个原生 Simai 音符 token 的额外信息。`l` 为左手（蓝），`r` 为右手（红），`m` 为左右任选（灰白）；`m` 不表示双手同时击打。没有标注的音符沿用原皮肤。标注不得改变原音符的时间、几何、数量、Each、Break、EX、Mine、音效或 Muri 语义。

标注作为 token 的最后一段连续文本出现，不允许在它和音符之间插入空格。只有小写 `l`、`r`、`m` 是合法手别；裸 `m` 继续属于原生 Mine 修饰符。

## 简写

```text
1~l/5~r,
2h[4:1]~m,
A1~r,
1-5[4:1]~l,
1m~l,
```

Tap、Hold、Touch、Touch Hold 的 `~l` / `~r` / `~m` 只标注本体。Slide/Wifi 的简写同时标注可见头和完整轨迹；无头 Slide 只对实际存在的轨迹生效。含 `*` 的多分支 Slide 使用一个组尾简写时，各分支轨迹取得相同手别。`12~l` 不合法：相邻数字簇必须先展开成独立音符。

## 复杂写法

单轨 Slide/Wifi：

```text
1-5[4:1]~[head=l;track=0:l|0.5:r],
```

同头多分支 Slide，分支号按源文本中 `*` 从左到右的 0 基顺序：

```text
1-5[4:1]*-7[4:1]~[head=l;branch0=0:l|0.5:r;branch1=0:m],
```

`head` 可省略；它是整个同头组的共同标注。单轨复杂写法必须恰有一个 `track`，多分支复杂写法必须为每个原生分支提供恰好一个连续编号的 `branchN`。`track` 与 `branchN` 不能混用。非 Slide 音符暂不接受复杂写法。重复键、未知键、缺分支、越界分支均为标注错误。

每条轨迹是 `进度:手别` 节点序列，以 `|` 分隔。首节点必须为 `0`；后续进度必须为有限十进制数，严格递增且小于 `1`。节点定义从该进度起生效的手别，区间左闭右开，终点 `1` 取最后一段的手别。例如 `0:l|0.5:r` 在精确 `0.5` 时已为右手。不接受负进度、重复进度、`1` 节点或空区间。

进度只计轨迹本体的运动时间，不计等待阶段。链式 Slide 以解析所得每个原生段时长累加并除以总运动时长，不按段数均分；因此换手点可以落在任一原生段内部。Wifi 的旧简写和普通节点序列仍把所有展开路径视为整体，兼容已有文本。

## Wifi 双扇区与显式单手

Wifi 可在原有 `track` 或 `branchN` 的值内声明模式，不增加容器键：

```text
1w5[4:1]~[head=l;track=split:0:l|0.5:r&0:r|0.75:l],
1w5[4:1]~[track=single:0:l],
1w5[4:1]*-7[4:1]~[branch0=split:0:l&0:r;branch1=0:m],
```

`split:` 后必须恰好有两条完整节点序列，由一个 `&` 分隔。每条序列独立遵守首节点为 0、进度严格递增且小于 1 的规则。第一条为本地扇区 0（手动界面显示“扇区 1”），第二条为本地扇区 1（界面显示“扇区 2”）；它们分别对应原生 `wifiLanePoints` 两侧的稳定索引 0 和 2。扇区不是固定的屏幕左右半区。分支号仍为整个原生同头组的源文本顺序，普通 Slide 分支可与 Wifi 分支并存。

`single:` 声明整条 Wifi 轨迹由同一只手执行，所有节点必须为相同的 `l`、`r` 或 `m`。同手的重复节点合法，保留编辑边界。`single:0:m` 表示整条轨迹选择左手或右手其中一只；不会在内部自由换手，也不代表第三只手或双手。可见头仍是独立击打，`head` 可使用另一只手，等待阶段不占用打头的手；例如 `head=r;track=single:0:l` 合法。单手模式不证明该原生几何或当前上下文实际上可由单手完成，可行性由自动算法的实际动作及判定回放审查。

两种显式模式只允许绑定原生 Wifi 分支。未知模式、少于或多于两扇区、空扇区、单手模式换手、普通 Slide 使用 Wifi 模式均为标注错误。任一分支的模式不合法时，整个 token 的标注不绑定；原生音符仍保留供实时预览，严格验证失败。原有 `~l` / `~r` / `~m` 和 `track=0:l|...` 保持原语义，不自动解释成显式单手或双扇区。

保存、格式化和 worker snapshot 重建保留模式及源分支归属。批量设置手别将显式模式内所有目标节点设置为所选手，保留模式和节点边界。手动区间按分支和扇区独立编辑；显式单手只提供一个整轨手别选择。模式仅在用户显式切换时改变。混合手别的双扇区切换为单手时，必须重新选择整轨手别才能写入。

旋转保持本地扇区编号。左右或上下镜像按原生几何交换两条扇区序列，默认保持手名；只有明确选择交换手别时才同时对调 `l/r`。镜像两次恢复原文。纯 Simai 导出移除整个标注，保持原生音符、几何和时间。

预览与视频导出共用场景描述和 QSG：每行 Wifi 轨道素材沿原生中心运动轴切成互补半平面，两部分独立按运动进度染色；两侧星使用所属扇区，公共中星按同一轴分色。显式单手保留原生三路径并整轨同色，在公共移动星附近添加圈“1”标识，与普通同色标注区别。关闭手序显示后不产生裁切或模式标识，沿用原始素材。

本节为本轮实现契约。新增解析、变换、手动草稿、共享场景和 snapshot 回归的构建与运行结果，以本轮主代理日志为准；不能沿用下文历史验收结论声称新模式已验证。

## 词法与诊断

解析器先在音符层识别并剥离 `~` 尾缀，再把未改动的原生部分交给既有 Simai 解析。复杂容器内部的 `m` 不能成为 Mine，`|` 不能成为音符分隔符，`*` 仅在容器外划分原生分支。

标注错误与原谱错误分别记录。实时解析仍保留可识别的原生音符供预览，错误标注不绑定错误手别，也不能吞掉后续逗号或音符；严格验证报告标注错误并判该文本无效。诊断范围指向原文的标注尾缀，使用现有的 1 基行、列坐标；多分支 marker 保留其源文本分支号与标注范围。

典型非法输入：

```text
12~l,                              // 数字簇归属不明
1~z,                               // 手别无效
1~[head=l;track=0:l],             // 非 Slide 不接受复杂写法
1-5[4:1]~[head=l;track=0.5:r],    // 轨迹缺少起点 0
1-5[4:1]~[track=0:l|0.5:r|0.5:m], // 进度未严格递增
1-5[4:1]~[track=0:l|1:r],         // 终点 1 不作为节点
1-5[4:1]*-7[4:1]~[branch0=0:l],   // 缺少 branch1
1-5[4:1]*-7[4:1]~[track=0:l;branch1=0:r], // 两种轨迹归属混用
```

保存保留标注文本；另提供导出纯 Simai 的独立操作，剥离标注后不能改变原生谱面语义。镜像和旋转默认保留手名；只有明确选择交换手别时才将 `l` 与 `r` 对调，`m` 不变。

## 当前实现与验证

- 简写、复杂单轨、同头多分支、链式 Slide、Wifi 旧整体轨迹及显式 Split/Single 已接入解析与严格诊断；Single 换手和非 Wifi 使用显式模式均拒绝，错误标注与原谱错误独立，源码列范围可定位。
- 手动区间面板支持 Wifi 模式选择、按源分支和扇区编辑，以及 Single 整轨同手选择；批量赋色保留显式模式和节点边界。保存、格式化、镜像、纯 Simai 导出和 snapshot worker 重建已接通，操作及验收契约见[手序手动工具](HAND_ORDER_MANUAL_TOOLS_SPEC_ZH.md#本轮-wifi-模式扩展)。
- 预览可切换手序显示；Tap、Hold、Touch、Touch Hold、Slide 和 Wifi 的主体按手序染色，Wifi 双扇区独立分色、显式单手显示圈“1”，类型轮廓、原素材与特效仍保留。Touch 重叠边框、Touch Hold 进度边框、引导圈、判定与 Muri 特效层沿用原色。
- 内置 SD/DX 皮肤现有 `hand_order/l`、`hand_order/r`、`hand_order/m` 三套从原 PNG 生成的透明素材；Break/Each 留有原色顶部提示，EX 图层叠加在染色底图上。自定义皮肤缺少相应素材时回退到原有 shader 染色。
- 时间轴与圆形预览共用手序显示开关和所选 SD/DX 皮肤，显示对应的头、长条及分段轨迹素材。Wifi 双扇区在扁平箭头内分成互补两半，显式单手显示圈“1”；未标注和关闭手序时恢复原谱。时间轴缺少预制手序素材时按舞台 shader 公式生成内存缓存，不改写皮肤文件。验证见 [时间轴手序皮肤](../../qa/hand_order/TIMELINE_STICKING_SKIN_20261023_ZH.md)。
- 视频导出可跟随预览、强制原谱或强制手序；当次解析后的开关进入 snapshot，CLI 使用 `--hand-order annotated|original`。封面图框沿用预览显示选择。
- 保存保留标注；格式化及镜像/旋转保持标注归属，菜单提供带左右手交换的镜像命令；独立“导出纯 Simai”不更改当前文档的路径与保存点。
- 本轮截至 2026-10-22 的 MiaCode Release 构建成功，19/19 项相关 CTest 全部通过，用时 14.78 秒，覆盖解析、变换、补全、手动区间及真实离屏 QML、预览、snapshot、音效等相关回归。该结论独立于下述历史验收记录。
- 本轮真实 OpenGL QSG 离屏帧及图像审查已通过：独立轨道层两侧分色的错侧像素为 0；同一精确 50% 运动时刻只有对应扇区的移动星从蓝变红；Single 圈“1”可见；关闭标注后的帧与无标注原谱逐像素相同，snapshot worker 帧与直接场景逐像素相同。证据为工作区 `logs/hand_order_completion_wifi_render_2.log` 和 `fixtures/hand_order_wifi_render/`。
