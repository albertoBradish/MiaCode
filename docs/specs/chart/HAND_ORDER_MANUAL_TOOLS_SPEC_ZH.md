# 手序手动工具（阶段 A）

本文记录人工手序标注工具和 Wifi 模式。独立 slide 结构拆分见[拆成独立 slide](NATIVE_SLIDE_SPLIT_SPEC_ZH.md)。

## 命令与入口

主工具栏“手序”、调整菜单下的“手序”和编辑器右键菜单提供本页相同六个手序命令。相同入口另有独立结构命令 `hand_order.split_native_slide` / `Ctrl+Alt+5`，先预览再一次应用，详见[拆成独立 slide](NATIVE_SLIDE_SPLIT_SPEC_ZH.md)；它不属于手序区间染色。快捷键沿用 ShortcutRegistry，可在首选项的快捷键页重新绑定，菜单展示当前绑定。

| 命令 ID | 行为 | 默认绑定 |
| --- | --- | --- |
| `hand_order.set_left` | 选中完整音符设为左手 | Alt+W |
| `hand_order.set_right` | 选中完整音符设为右手 | Alt+E |
| `hand_order.set_either` | 选中完整音符设为无色/任选 | Alt+Y |
| `hand_order.split_annotation` | 拆分星星手序区间并打开区间编辑器 | Alt+T |
| `hand_order.bisect_annotation` | 二分光标当前 Slide 或选中 Slide 的轨迹区间，首次默认前左后右 | Alt+C |
| `hand_order.swap_hands` | 交换选中完整音符既有标注中的左右手 | Alt+Q |

一键二分无选区时仅处理光标所在 Slide，表中其余设置手别、交换与区间编辑命令无选区时禁用。键盘路径还要求源编辑器焦点，快捷键录制期间不编辑谱面。原生菜单平台由菜单 Action 独占绑定，其他平台由 ShortcutBindings 独占绑定，工具栏和右键菜单只显示绑定文本。

手序文案使用真实编译的三语 ID catalog；ID 消息统一放在 TS 的空 context，不能依赖新版 `lrelease -idbased` 把命名 context 转成 ID。运行时切换语言刷新工具栏、区间行和反馈，保留原文、临时手别选择与草稿身份；翻译刷新不执行编辑。

## 完整 token 的批量编辑

生产解析器暴露其原生词法扫描所得的 UTF-16 token 范围。批量命令只处理完整落入选区的音符，整个同头多分支 slide 视为一个 token；部分 token 跳过并报告数量。相邻数字簇按原 each 语义展开为 `1~l/2~l` 等独立音符。空白、CRLF、逗号、反引号、注释、时间指令和原音符修饰保留。

对完整 slide 批量赋值会覆盖其头和全部轨迹分支的既有换手。`~m` 表示用户明确指定“任选”，不代表未推断或需要双手。非法手序标注保留原文，反馈列出原始行、列和诊断；同批次其他合法完整 token 可独立修改。编辑器底部反馈可点击查看完整诊断。

所有文本改动使用一个 Scintilla 原生编辑事务。相同选区重复赋同手、重复拆分且没有新节点时，不创建空撤销动作。

## 手序区间

### 一键二分与交换左右手

`Alt+C` 不经过区间弹窗，直接写入选中完整普通 Slide（含链和同头多分支）的手序。没有换手节点时，按整条轨迹的实际运动时间对半，写入 `track=0:l|0.5:r`；已有头手别保留，省略的头继续省略。已有两个或更多节点时，对每个当前区间分别增加中点，继承该区间手别。因此第二次执行得到 `0:l|0.25:l|0.5:r|0.75:r`，第三次得到八段；相邻同色节点作为编辑边界保留。极短区间没有可表示的 double 中点时保持原区间。它不改变 Wifi 的整体／双扇区／单手语义，遇到 Wifi token 跳过并报告不支持。

`Alt+Q` 只交换选区内完整合法 token 的 `l/r`，覆盖头、全部轨迹分支、Wifi 双扇区及单手模式；`m`、未标注音符、进度数值、模式与原文格式保留。连续交换两次恢复逐字符相同的源文。部分 token、注释和选区外内容不改动。

无选区按 `Alt+C` 时，从原生解析器的完整 token 范围定位光标所在 Slide，手序后缀也属于此范围；只改该 token，同头多分支保持整体操作。光标在空白、分隔符、注释或非 Slide 音符上时不改，文件末尾紧邻最终 Slide 时可处理该 Slide。成功后选中替换后的完整 token，再按 `Alt+C` 继续二分同一条，不扩大到邻近 Slide。

两条命令均沿用可重绑注册表和统一菜单入口；交换左右手仍要求选区，每次有变化的执行仅产生一次原生编辑事务，可一次撤销。旧 `Alt+T` 继续提供按原生段边界拆分、手工编辑区间的工作流。

链式 slide 在原生段运动时长的累计比例处增加节点，不计等待。1 秒和 3 秒两段的分界为 0.25。当前原生解析器会把多段逐段时长签名先合计，再按形状长度重分配；工具以最终解析的运动起止时间为准，不把签名中的名义时长当作最终段时长。单原生段（含 Wifi 整体轨迹）增加 0.5 节点。新节点继承所在区间的手别，既有节点全部保留，包含相邻同色节点；重复边界不新增。省略的头不因拆分而获得新标注。

区间编辑器的下拉框只修改对应的头或轨迹区间。所有分支的全部轨迹区间完成赋值后，“写入谱面”才可用；可见头允许保持未指定，从而保留原皮肤。一次点击以一个事务写入完整合法容器，未完成的未知轨迹不会用 `m` 填空。

未标注 slide 的拆分不直接修改谱面，先生成临时区间。临时选择按文档打开代次、难度和全文 SHA-256 隔离，当前会话最多保留最近 64 个编辑版本；每个版本保留所有已拆 token 的草稿，面板显示当前选区；标注写入产生长度变化时，会重定位其他未写草稿。回到相同文本版本（包括撤销/重做）可恢复。它们不写入谱面文件，也不跨应用重启持久化；面板对此给出明确提示。关闭面板后可重新选择该 slide 执行拆分以恢复。无目标或非法目标的再次拆分不打开之前的结果。

原生谱面错误可能影响后续运动时长，因此拆分遇到此类错误会返回诊断并保留原文，要求先修正谱面。进度序列化保留 double 的可往返精度，并展开科学计数为语法允许的十进制；输出重新交严格解析器验证。

## 阶段 A 历史验收入口与边界

- `hand_order_edit_spec`：完整/部分选区、数字簇、UTF-16、CRLF、注释、分支、1+3 秒链边界、同色节点、幂等性、非法输入、极小/近 1 进度以及原生语义投影。
- `hand_order_tools_spec`：真实 EditorController 二分与交换事务、Scintilla 一次撤销、重复二分、反向选区、UTF-16 光标定位及邻近 token 保护。该小型宿主复用原生 Scintilla 编辑能力，不等同于启动主 GUI 验收。
- `qml_shortcut_binding_spec`：注册表与执行表一致、实际 QML 触发、重绑、禁用及录制焦点。
- `shortcut_preference_persistence_spec`：七条默认绑定、改绑和重新创建注册表后的持久化。

上述阶段 A 验收未运行自动算法，不生成手部动作可行性、压力或置信结论，也不改变原生 slide 结构。主 GUI、真实谱面和跨进程重启的临时区间均不属于上述合成离屏验收的证明范围。

## 本轮 Wifi 模式扩展

本轮已在同一个区间编辑器中实现 Wifi 的“兼容整体轨迹”“双扇区”“显式单手”模式选择。模式、语法、分支归属和几何变换遵守[Wifi 双扇区与显式单手契约](HAND_ORDER_ANNOTATION_SPEC_ZH.md#wifi-双扇区与显式单手)。模式只由显式选择改变；旧 `~l` / `~r` / `~m` 及普通 `track=0:l|...` 保持兼容整体轨迹语义。

双扇区模式按“源分支＋扇区”列出两条独立的进度区间序列，手别选择只修改对应区间。界面扇区 1/2 对应原生 `wifiLanePoints` 两侧的稳定索引 0/2，各自从进度 0 开始；它们不代表固定屏幕左右。拆分单段 Wifi 时，两序列分别增加 0.5 边界，继承各自手别并保留已有节点。所有目标扇区的区间完成赋值后才允许写入，未知区间仍不以 `m` 补空。

显式单手模式只提供一个“整条单手”选择，统一修改整条轨迹的手别；已有同手节点作为编辑边界保留，不能在该模式内写入换手。`single:0:m` 表示整条选择左手或右手其中一只。可见头继续独立编辑，例如 `head=r;track=single:0:l` 合法。混合手别的整体或双扇区切换为单手后，需要重新选择整轨手别才能写入；显式切回双扇区后，可分别编辑两序列。

完整 token 的左手、右手、任选批量命令会覆盖可见头及全部轨迹节点的手别，同时保留已有的 `split:` / `single:` 模式和节点边界。例如：

```text
1w5[4:1]~[track=split:0:l|0.5:r&0:r],
// 批量设为任选后：
1w5[4:1]~[head=m;track=split:0:m|0.5:m&0:m],
```

保存、格式化、临时草稿和 snapshot 重建保留模式、源分支及扇区序列。旋转保持本地扇区；左右或上下镜像交换两扇区，默认保持手名，仅明确选择交换手别时才对调 `l/r`。纯 Simai 导出移除整个标注。上述操作不改变原生 Wifi 的时间、几何、音符数量或音效。

共享预览与视频导出场景把 Wifi 轨道沿原生中心运动轴分成两部分，按各扇区区间独立着色；两侧移动星保留完整原生形状并使用所属扇区手别，公共中星分色。显式单手保留原生三路径，并在公共移动星附近显示圈“1”，与普通同色标注区别。关闭手序显示后恢复原始轨道、移动星及素材，移除模式标识。

本轮独立 Release 验收已通过解析、批量变换、补全、区间编辑、真实离屏 QML、预览场景、snapshot、音效及头部图层回归；这些是本轮证据，与上述阶段 A 的历史 8 项分开记录。`wifi_hand_order_render_spec` 已通过真实 OpenGL QSG 离屏渲染，并由主代理查看输出图确认：

- 独立轨道层两侧分别检测到 27810 个蓝色像素和 27016 个红色像素，跨错扇区像素为 0。
- 同一精确 50% 运动时刻的移动星对照证明，扇区 1 从蓝色变为红色，扇区 2 保持红色；判据直接检查颜色，不以消轨导致的图像变化充当换手证据。
- 显式单手的圈“1”可见；隐藏双扇区或单手标注后的帧与无标注原谱逐像素相同；snapshot worker 重建帧与直接场景逐像素相同。

真实 QSG 验证使用 `QT_QPA_PLATFORM=windows` 的隐藏离屏 surface，未启动主 GUI；`offscreen` 平台在该环境不支持 OpenGL，不能用其初始化失败代替渲染结果。工作区证据为 `logs/hand_order_completion_wifi_render_2.log` 和 `fixtures/hand_order_wifi_render/`，正式验收入口见 [WifiHandOrderRenderSpec.cpp](../../../src/tools/video_export/WifiHandOrderRenderSpec.cpp)。本轮手动工具与渲染验收仍只使用合成谱面，不构成真实谱面或单手动作可行性的证明。
