# 基础排布

状态：2026-10-22 已经主代理独立验收。完整 Release 构建及 23 项相关 CTest 全部通过，包括基础变换、真实编辑桥、离屏按钮交互、快捷键重绑与持久化、翻译资源；没有执行真实主 GUI 人工验收。基础排布与[自动手序](BASIC_AUTOMATIC_HAND_ORDER_SPEC_ZH.md)是两个独立命令。

工具栏提供直接可见的“基础排布”按钮，手序菜单和编辑器右键也可触发，默认快捷键为 `Ctrl+Alt+B`，沿用 ShortcutRegistry，可在首选项重新绑定。快捷键要求谱面编辑器焦点，快捷键录制期间不执行；没有选区时处理当前难度正文，有选区时仅处理完整选中的原生 token。同头多分支作为一个 token，部分选中的 token 保留。

## 确定性位置规则

- 普通外键 1–4 为右手，5–8 为左手，Hold 整体沿用该手。
- Touch 和 Touch Hold 按解析所得传感区实际横坐标分配左右，不按编号机械划半。C 区和中轴传感区没有左右偏好，明确标为 `m`；这里的 `m` 表示任选一只手，不是未知或双手。
- 普通及链式 slide 的整条轨迹沿用原生运动起点所在半屏的手，即使后续跨屏也不预先产生换手。可见头按头位置独立赋值；无头轨迹不新增可打头。
- 未标注的 Wifi 生成显式 `split:`。原生扇区 0/1 对应外侧路径 0/2，比较两端点的横坐标，较左的扇区分配左手，另一扇区分配右手；即使两端都在同半屏，仍保留两只不同手。横坐标相同时以原生扇区顺序作固定裁决。基础排布不推断显式单手 Wifi。

标注格式遵守[手序语法契约](HAND_ORDER_ANNOTATION_SPEC_ZH.md)。已有任何标注均按原文保护，包括 `~m`、复杂换手、Wifi 旧整体、显式 Split/Single 和已有非法标注。非法标注会报告诊断，不能被基础排布悄悄修写。无标注数字簇按原 Each 关系展开为独立标注音符。

## 编辑事务与边界

本命令使用生产解析器的 UTF-16 源 token 范围、原生几何和已有手序序列化器。原生语法错误阻止本次写入；输出重新进行严格解析。时间、几何、音符数量、修饰和 Each 保持不变，只增加手序标注。

一次执行通过现有 Scintilla 桥提交一个编辑事务，一次撤销恢复完整操作。空选区处理当前难度后保留原光标的对应位置；有选区时沿用现有选区事务。重复执行保留已有标注，没有变化时不创建空撤销。反馈分别列出改写、保护已有标注、部分 token、不支持及诊断数量，并说明没有动作可行性回放。

基础排布不运行完整判定回放、束搜索或预算计算，也不把左右分配解释为人体可玩性、官方判定或置信保证。后续自动算法可使用同一位置规则作为软偏好，再根据上下文判断实际动作和换手；人工标注仍是受保护约束。

基础排布写入的是正常持久标注，自动手序默认会保留。若希望继续自动优化，选取待优化的完整音符，运行“基础自动手序”，并在结果面板勾选“重算选区已有手序”后重新分析；没有选区时对应当前难度范围。检查预览后再应用。基础排布不会自动开启该选项或更改已有标注的保护偏好；选区外标注继续受保护。

## 验收入口

- `basic_hand_order_layout_spec`：1–8/持续音符、跨屏及链式 slide 起点手、Touch 中轴、Wifi 双扇区与同侧扇区、现有标注保护、部分 token、UTF-16/CRLF、原生投影及幂等性。
- `hand_order_tools_spec`：真实 Controller 文本事务、Scintilla 一次撤销、空选区当前难度、可见工具栏按钮和实际点击。
- `qml_shortcut_binding_spec`、`shortcut_preference_persistence_spec`：独立默认绑定、实际 QML 触发、空选区、重绑、录制/焦点守卫及重建注册表后的持久化。

当前验证只使用工作区合成资料；主 GUI 和真实谱面结果另行记录，不沿用旧版本通过记录推定本轮新增按钮已经验收。
