# 手序标注时间轴预览修复

日期：2026-10-23（UTC）。开发由 GPT-6.1-Sol / XHigh 执行，主代理复核、构建与发布。

## 根因与范围

完整 SimaiParser 在原生音符解析前拆分 `~l`、`~r`、`~m` 和复合 `~[...]` 后缀；时间轴快速解析器此前直接把后缀当成原生语法。Tap、Hold、Touch 等可能被拒绝；Slide 的复合标注可能被当成原生修饰符或时值括号，`~m` 还可能误触发 Mine 标记。

修复复用既有 `hand_order::splitToken`，仅将原生部分传入时间轴音符解析。行扫描采用与完整解析器相同的标注恢复边界，避免坏标注中的 BPM、细分或 HS 文本改变后续音符。保留原始正文、列号、逗号锚点和选择范围。

时间轴沿用原生音符图标和轨迹显示；本修复不新增时间轴手别染色功能。圆形舞台的手序着色仍由既有预览链处理。

## 验收方法

`timeline_model_spec` 使用 22 个合成音符，覆盖 Tap、Hold、Touch、TouchHold、Slide、Wifi，以及 Each、Break、EX、Mine、星形 Tap、无头轨迹、多分支、链式轨迹、Wifi 双扇区与显式单手。

- 对照完整解析器，比较音符数量、原生类型、修饰、时间、位置、HS 和 Each 状态。
- 使用内置 SD 素材生成实际时间轴场景，对照音符/轨迹精灵及长条、TouchHold、烟花几何。
- 验证整文应用手序、修改和删除简单后缀、复杂标注替换的增量刷新。
- 验证错误标注恢复、点击音符导航、预览跟随选择和仅选中后缀时的导出范围。

修复前同一合法合成谱的完整解析结果为 22 个音符，时间轴仅剩 4 个，相关显示、时长和导航回归失败。构建、修复后测试、归档与安装的最终执行结果保存在工作区 `exports/timeline_preview_fix_20261023/`，避免把发布提交身份反复写回源码。
