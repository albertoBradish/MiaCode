## 已定位的通用问题

- 固定双押锚点之间的连续三连绕手需要保留流动手，下一组自然换另一手；此时交叉双押有上下文依据。
- 短跨侧四键可在中间交接，但已有 hold/待起滑轨道占用另一手时，应保留原同手扫动。
- 完整八键圆周不能仅因为记谱格为十六分而被按左右半场拆断。
- HOLD 名义尾接新 strike 时，只提供完整保持模板会虚增移位压力；安全释放候选仍须通过原完整判定回放。
- TAP、HOLD 头、SLIDE/Wifi 星头的自然姿态评价应按最终责任手一致计费，包含由旧轨道顺带触发的头。
- 名义滑动输入可能提前消耗后继 tap；保持原生 marker 和判定窗口不变，改为搜索有界的实际输入时序。
  最小回归中，A4 接触提前约 140ms 消耗后继 4；实际滑动提前两个判定 tick（约 11ms）后，两者都可通过同一严格回放。
- 连续的“旧轨道触发新星头”有多代来源关系。跨窗口必须保留已提交输入的真实消费来源传递闭包，
  不能仅留下上一代 marker 而丢掉触发它的更早 DOWN。

组件补充标注。此锁定结果证明模型能够表达参考动作，不等同于自由推断已与参考完全一致。
