# 持续动作与物理计费细化（算法 v16）

以 v15 提交 `d2c9ff0` 和同一批人工语料为基线。本轮没有按曲名植入答案，也没有改变四组预设数值或默认 3 亿预算。
真实谱面、音频、逐音符差异与官谱视频只保存在本地工作区。

## 修正范围

- 固定 HOLD、独立 tap 和轨迹的实际停驻，允许按三维上下穿过的假设参与搜索，二维前臂相交按重叠时间软计费。
  两只手同时在运动，或一只手在滑条、另一只手在连扫时，仍优先规避穿插；同头发散分支的左右空间次序没有放宽。
- 交叉几何统一放入物理动作模块，按每手唯一中心的时间区间计费。重合逻辑轨迹和等速细分不能重复增加同一物理交叉。
  只采样实际存在对手重叠的区间，避免独立长轨迹的采样耗尽搜索预算。
- 浅出张头部继续按一次短击计费；不可秒松的 HOLD/TOUCH HOLD 另按必需按压段中的跨侧姿态积分。
  同一物理手的多个保持来源只计一份，已提交保持不能因附加逻辑任务再次扣姿态代价。中央 TOUCH HOLD 没有虚构的跨侧压力。
- 同侧四颗连续邻键在每步不超过 0.13 秒时保留连扫识别，修复略低于部分扫阈值时把扫尾单独交给另一手的问题。
  跨侧四键可连续分段的规则保留。

这仍是有限的工程动作模型；静态投影不证明三维人体可行性，完整回放也不等于真人手感验收。
没有放宽原生 HOLD、Touchgroup、EX、BREAK 或 WiFi 判定。

## 聚焦验证

Release、并发上限 4。13 项聚焦 Spec 全部通过，日志在工作区 `logs/ergonomic_v16_final_build.log` 和
`logs/ergonomic_v16_final_ctest.log`。涵盖玩家负荷、身体姿态、重合轨迹、局部窗口、完整回放、异步失效与 DX 输入。

`hand_order_ergonomics_spec` 的 120 个组合覆盖原有 FFT 配置、DX TOUCH 变体及中速同侧扫，分别检查四预设、镜像和
适用的 EX/BREAK 变体；既有同头、三扫、出张与一笔画结果保持。另验证重合逻辑轨迹与轨迹细分的交叉统计一致，
逻辑滑条的实际等待区间不会被误算为运动；长 HOLD 跨侧姿态代价随必需按压时长增加，中央 TOUCH HOLD 不受此项影响。

## 人工语料对照

同 v15 的原生 marker 口径，分支共用星头仍按 marker 计数。完整清除目标难度的旧标注后分别运行四种预设，
逐 marker 核对原生时间、几何、修饰符、顺序和数量；参考答案不作为输入锁。反事实预算为 0，未决补色开启，
未验证补色单列。结果保存在工作区 `exports/ergonomic_v16/validated/`。

本轮改善集中在 Prism 的一笔画与待起滑星头、Synthesis 的轨迹旁 C/E TOUCH 分工；不同手别仍可能代表可行的其他打法。
Deep in Abyss、Destined Marionette 仍有人工一致性回退，所有新增差异保留在 `regression_vs_v15.json`，不能称为全面改善。
两张复杂谱在默认预算下的未验证行仍需复核。预设仅作为可调评分，不根据曲名自动选一组参数。
