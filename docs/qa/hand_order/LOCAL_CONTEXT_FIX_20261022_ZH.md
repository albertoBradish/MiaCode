# 基础排布与自动手序局部求解验收

日期：2026-10-22。开发使用 GPT-6.1 Sol / XHigh；主代理独立检查源码、执行 Release 构建和测试。构建并发不超过 4，所有产物和运行目录均在隔离工作区。

## 本轮结果

- 新增“基础排布”按钮和可调快捷键 Ctrl+Alt+B：1–4 右手、5–8 左手；普通 slide 整条沿用起点手；Touch 按实际位置，中央无偏好标为任选；Wifi 使用双扇区。默认保护已有标注。若随后自动优化，须勾选“重算选区已有手序”并重新分析。
- 自动算法 v4 使用左手 6、右手 3 的初始位置，携带后续真实手位与占用。普通关联以局部前后文为主，随时间和间隔音符衰减；真实持续动作、同刻、Touchgroup 和输入消费仍作为约束。
- 搜索预算不再被递归时间邻接串成整谱大块。先尝试常手、常规通道与时刻，必要时扩大候选；困难窗口不会自动否定独立的已验证结果。置信计算优先让出基本求解预算。
- 最终回放保留全部原生音符，包括未决对象；使用活跃事件集合减少扫描。失败上下文可见，无候选时不再显示虚假的零压力。

完整 MiaCode / MiaCodeLauncher Release 构建成功；23/23 相关 CTest 通过，0 失败，11.97 秒。包括解析、手序编辑、两种 slide 拆分、局部求解、Touchgroup、608 个原生 slide 正例及其截断反例、Wifi、预览/音效、服务请求身份、真实 Qt 翻译资源、离屏控件、快捷键和隔离运行路径。

## 验收范围

本轮没有启动真实主 GUI，也没有使用桌面自动操作。实际主窗口的视觉布局、焦点和个人手法仍按 [手动清单](MANUAL_CHECKLIST_ZH.md) 检查，未替用户勾选。高密度复杂片段仍可能受有限搜索预算限制；未决不是无色，也不是已证明不可打。置信分不是正确率。
