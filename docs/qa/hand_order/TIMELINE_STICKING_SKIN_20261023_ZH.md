# 时间轴 Sticking 皮肤

日期：2026-10-23（UTC）。本次在音符可见性修复基础上，接入时间轴的手序素材。

## 显示规则

- 时间轴与圆形预览共用“显示手序标注”设置。打开时使用蓝色左手、红色右手、灰白色任选主体；关闭时恢复原生素材。
- SD、DX 优先加载所选皮肤中的 `hand_order/l`、`hand_order/r`、`hand_order/m` 预制艺术，保留 Break、Each、EX、Mine 的原生类型细节。没有标注的音符保持原样。
- Hold 的两端和主体使用对应手序素材；Touch、TouchHold 使用对应的复合图，TouchHold 持续时间线同步标识手别。
- Slide 的头和轨迹分别取各自标注。轨迹按运动进度分段换色，等待时间不计入换手比例；多分支保持源顺序对应。
- Wifi 双扇区在时间轴的扁平轨迹箭头内采用互补的两半显示，各自按标注节点换色；两半是扇区身份示意，不代表圆形舞台中的空间方向。显式单手模式显示圈“1”。
- 自定义皮肤缺少预制手序主体时，运行时按舞台回退染色公式生成缓存素材，不改写用户的皮肤文件。

手序显示只反映已有标注，不证明手法可玩。原生音符、时间、判定、音效、Muri 和导出语义不因时间轴着色改变。

## 验证入口

`timeline_hand_order_skin_spec` 比较快速时间轴与完整解析器的手序数据、检查预制 PNG、用真实时间轴 QSG 控件生成离屏像素，并验证开关往返、SD/DX 切换和轨迹换手。`timeline_model_spec` 保留上一轮原生几何、时长、导航与编辑刷新回归。共享后缀解析还需通过 `simai_parser_spec` 及相关手序回归。

运行 `timeline_hand_order_skin_spec <输出目录>` 可保存 SD/DX 原谱和手序帧，用于视觉核查。最终执行日志、发行身份和安装哈希保存在工作区 `exports/timeline_sticking_skin_20261023/`。

## 与算法反馈的边界

测试者另外反馈复杂多轨手序可能不可执行，已确认截图来自“基础排布”；只有截图尚不能还原重叠时段，仍需具体谱面片段。该反馈与手序占用、可达性及换手连续性一起交由并行算法任务核查，不以皮肤显示正确替代算法验收。换手不重置原生 Slide 判定，也不能清空已有位置和占用状态。
