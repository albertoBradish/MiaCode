# 隔离版手序功能手动验收清单

这份清单只使用同目录的合成 `maidata.txt`，不需要音乐或真实谱面。自动化验证记录另列；下方复选框留给操作者勾选，未勾选不代表已经通过主 GUI 验收。

## 准备

1. 将整个发布包解压到一个可写的新目录，从包根目录的 `MiaCode.exe` 或 `Start_HandOrder.ps1` 启动。不要直接运行 `app/MiaCode.exe`。
2. 首次设置可以跳过。打开本目录的 `maidata.txt`；建议先复制这份合成文件到包内 `acceptance_work/maidata.txt`，把保存和重开测试放在副本中。
3. 确认最近文件只出现本次合成谱面，包内出现独立 `runtime/`。如出现正式版最近文件或要求迁移正式版数据，停止测试并反馈，不继续打开那些文件。
4. 每次使用编辑快捷键前，先点击源码正文。合成谱包含 Advanced、Expert、Master 和 Re:Master 四个难度，分别对应下方测试。

## 建议优先完成的项目

- [ ] **中文与布局**：工具栏显示“手序”，菜单和面板为可读中文，不出现 `hand_order.*` 键名。按常用窗口大小打开三个手序面板；文字可滚动、源码对照可选中复制，底部按钮可见且可点击。
- [ ] **基础排布与撤销**：Advanced 恢复无标注原文，点击正文并取消选区，按 Ctrl+Alt+B 或点工具栏“基础排布”。应处理当前难度，6 为左手、1 为右手；非模式旧标注保持原文，再执行没有新改动。Expert 的孤立跨屏链式 slide 应整条沿用起点手、不提前生成换手；部分选中的 token 不改。Ctrl+Z 一次恢复本次排布。
- [ ] **纵连、绕手与低压力回弹**：在合成副本临时输入 `(120){16}4,4,4,4,`，基础排布应为 `r,l,r,l`；输入 `(120){16}1,1,2,2,3,3,4,4,` 应为 `r,r,l,l,r,r,l,l`；输入 `(222){8}4,4,5,5,3b/6b,`，前四颗应为 `r,r,l,l`。另测 `(240){8}4/7,,2/5,,4,4,5,5,`，尾部仍应为 `r,r,l,l`，同 BPM 改成 `{16}4,4,4,4,` 才逐颗交替。再对简单旧标注运行一次，结果应能修正且不生成多余的第二次撤销。
- [ ] **临位 Touch 与外键双押**：合成副本的 `(120){8}B4/E4,B7/E8,B2/E2,B5/E6,` 应依次得到 `r/r,l/l,r/r,l/l`；`(120){12}B6,E6,,E2,B2,,E8,B7,,B3,E4,,` 应为 `l,l,r,r,l,l,r,r`。相邻外键 Hold 如 `4h[8:1]/5h[8:1]` 仍要分给两手。
- [ ] **交替星星旧标注修正**：合成副本输入 `(120){16}2x-5[16:1]~[head=r;track=0:r],,,7x-4[16:1]~[head=l;track=0:r],,,1x-5[16:1]~[head=l;track=0:r],,,8x-4[16:1]~[head=l;track=0:l],`，基础排布后四条整轨应依次为右、左、右、左；选区外及自定义多节点换手标注不被改写。
- [ ] **基础排布后自动优化**：基础排布写入后运行自动手序，默认保留已有标注。只有勾选“重算选区已有手序”并重新分析，才允许优化目标范围内的已有标注；先查看结果再应用，选区外标注继续保护。基础按钮不得自行改变该选项或偏好。
- [ ] **批量左右/无色与撤销**：切到 Advanced，选中源码中的 `6`，依次试 Ctrl+Alt+1、Ctrl+Alt+2、Ctrl+Alt+3，应分别得到 `6~l`、`6~r`、`6~m`；每次按 Ctrl+Z 恢复。没有选区时不得改动整首。
- [ ] **自动手序基本闭环**：Advanced 正文恢复原文后，Ctrl+A，再按 Ctrl+Alt+H。结果应包含两颗按键，通常为 6 左手、1 右手；能看到分数与压力说明。点击应用后源码出现手序，Ctrl+Z 一次恢复原文，Ctrl+Y 可重做。
- [ ] **自动结果定位与保护**：重新分析，点击一行“定位”应选中对应源码。关闭面板后修改正文、切换难度或重新打开文件，再次分析应对应当前文档，不能显示并应用旧文档的建议。
- [ ] **Wifi 自动结果与显示**：Re:Master 中选中 `1w5[2:1]`，运行自动手序并应用。应得到可保存的双扇区或明确单手方案；不能用 `~m` 冒充双手。预览中双扇区颜色可区分，关闭手序显示后恢复原皮肤。
- [ ] **手序区间拆分**：Expert 中选中完整 `1-3-7[2:1]`，按 Ctrl+Alt+4。应打开区间编辑器，按原生段边界显示区间；为所有轨迹区间选择左右手后应用。原生链仍为一条，只新增手序标注；不得变成多个 `/` 分隔的独立轨迹。Ctrl+Z 一次恢复。
- [ ] **独立 slide 拆分预览**：Master 中选中完整链及其 `~[...]` 标注，按 Ctrl+Alt+5。应先显示原文、转换文本、轨迹数增加、头数不变及玩法影响；此时正文尚未改变。点取消后正文和撤销历史不变。
- [ ] **独立拆分应用与重开**：再次 Ctrl+Alt+5 并应用。输出应含独立无头后段，原手序映射到各段；轨迹形状和运动起止时间保持，判定边界、计分、Each 或音效可以变化。Ctrl+Z 一次恢复。再应用、Ctrl+S 保存合成副本，关闭重开后标注和独立段仍在。
- [ ] **快捷键重绑与焦点**：在首选项快捷键页将“拆成独立 slide”改成一个无冲突绑定。新绑定能打开正确预览，原 Ctrl+Alt+5 不再触发；关闭重启后绑定保留。在快捷键录制框、设置输入框和只读差异文本中按编辑快捷键，不得修改谱面。测试后可恢复默认绑定。

## 扩展边界项目

- [ ] **混合不支持目标整批阻止**：在合成副本正文临时输入 `(120){4}1-3-7[2:1]/2w6[4:1],E`，全选后 Ctrl+Alt+5。应说明 Wifi 不支持此结构拆分并禁用整批应用，不能只拆前一条链。测试后撤销或恢复副本。
- [ ] **无色不代表未知或双手**：手动无色应写 `~m`；自动结果的未决、混合责任或预算不足不能靠 `~m` 填满。
- [ ] **Wifi 单手标识**：用手序区间编辑器将 Wifi 切为明确单手模式，选择一只手并应用。整轨应为同一手，显示圈“1”；保存重开后模式不丢。这个标识不保证实际手法可打。
- [ ] **两种入口一致**：工具栏、调整菜单、编辑器右键中的命令都对应正确功能，显示最新快捷键；没有一个入口把 Ctrl+Alt+4 和 Ctrl+Alt+5 混用。
- [ ] **视觉状态**：在暂停、拖动预览进度、改变窗口大小及主题后，手序颜色、Wifi 分区和单手标识仍正确；预览没有卡住或持续闪烁。
- [ ] **分析浮层与焦点**：若分析时出现进度浮层，完成后它应消失，不能挡住结果面板的定位和应用按钮；能取消时，取消应保留原文。关闭结果面板后，点击正文能继续编辑和使用快捷键。
- [ ] **语言切换**：在首选项切换中/英/日后重新打开手序面板，标题、结果状态、说明和按钮应使用同一语言，不残留旧语言或原始键名。
- [ ] **隔离复查**：退出后只在包内 `runtime/` 看到本次偏好、会话、日志等测试数据。不要把旧正式版配置复制进来。若怀疑写入正式版，保留本包日志并反馈。

## 反馈格式

请记录：包名/commit、失败项目、实际快捷键、窗口大小与缩放、最短合成源码、实际结果和期望结果；可附截图及本包 `runtime/logs/` 中对应时间段日志。不要提交真实谱面、正式版偏好或无关个人数据。

结构拆分改变原生对象，不能保证玩法语义等价；自动手序使用有限社区参考规则和动作模型，启发分不等于正确率。上述项目用于验证编辑流程、显示和保存行为。
