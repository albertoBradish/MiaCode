# 玩家模型第 10 版验收

默认能力/偏好参数为手速 5.5 次/秒、位移 6 半径/秒、体力容量 1、恢复半衰期 2.5 秒、打法偏好 0、
自然侧姿态权重 4。六项均可持久化调整。整谱默认工作预算 2 亿，上限 3 亿。

## 实测结果

单位为源 token 行，不能混称为真人满意度或逐组件手序正确率。

| 样本 | 完整回放验证 | 未验证补全／未解 |
| --- | ---: | ---: |
| 夜に駆ける，原官谱副本槽位 5 / 11 | 596/596 | 0 |
| ロストワンの号哭，原官谱副本槽位 5 / 13 | 878/878 | 0 |
| ウミユリ海底譚，原官谱副本槽位 5 / 13 | 683/683 | 0 |
| Pretender，原官谱留出样本槽位 5 / 12+ | 450/450 | 0 |
| Lance，用户标注的民间重制槽位 5 / 14 | 693/693 | 0 |

这五份输入共 3300 行均经完整回放验证，没有靠预算耗尽后的 fallback 填色。Lance 自由推断与参考的原生
音符、时间和几何完全一致，精确手序匹配从第 9 版的 669/847 提高到 792/847（93.51%）；参考缺标的 2 个组件
不计分。完整锁定参考和自由结果重新读入验证均为 693/693，重新读入自由结果没有追加修改。

普通样本第 20 行曾出现同手 HOLD 链尾接峰速回归，最终该 4 tap 的峰值已从 15.3073 降至 4.0519 半径/秒，
仍完整验证。该项按具体动作复核，未用新增验证集合的峰值变化掩盖回退。

## 稳定性和回归

- 17 项聚焦 Spec 通过，覆盖玩家模型、持久化、异步失效、布局、局部窗口、完整回放、时间轴、HOLD 释放、
  绕手、实际输入时序及多代触发来源。
- 修复 QSet 任意成员被当作组时间代表的问题，改用最早名义时间；依赖根、marker 和重要事件遍历固定顺序。
  固定 Qt 哈希种子与三个独立随机进程的输出、逐窗口工作量和行证据一致。该特定复现使用 1 亿预算，稳定地产生
  687 验证行和 6 个未验证补全；不能把确定性通过混称为该低预算配置全验证。默认 2 亿配置的整谱结果见上表。
- 四张原官谱持续作为回归和留出数据；没有在运行时写曲名、具体时间段或 Lance 专用键位答案。
