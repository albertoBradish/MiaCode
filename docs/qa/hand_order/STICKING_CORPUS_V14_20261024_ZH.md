# 五份人工手序语料对照（算法 v14）

用户提供的 `DATAERR0R`、`Destined Marionette`、`Synthesis` 正确标注包与此前两份范文，均仅在本地工作区 `exports/hand_order_gold_corpus/` 保存原谱和标注文本。`manifest.json` 记录来源、大小和 SHA-256。完整谱面、音频和图片不进入 Git 或测试安装包。本轮不公开 GitHub Release。

第 5 难度按原生音符本体及名义时间逐一对齐。比较的是 `~l/~r` 等标注文本，不把人工一致率当作人体可玩性证明。自动输出采用默认综合参数、3 亿工作单位搜索预算、重算旧标注、未决补色。

## 本轮规则与回归

- 不同键的连续 Hold 若前条名义尾部恰接后条头部，禁止同一手借判定允许的提前松手时间瞬移接下一个 Hold。合成回归覆盖 100、180、240 BPM。先行四份人工范文中找到的 44 组此类 Hold 接续均换手。
- Touch 扫按音符所在 BPM 和分音格核对相邻时间；A/D/E 同圈及跨圈相邻路径可保持同一手，单次双押中每颗 Touch 分别追踪责任手，避免同一源 token 的责任手相互覆盖。Synthesis 的 `E2/D2→A2→D3→A3→D4→A4` 与镜像段在默认预算下同人工稿一致。
- 综合默认玩家参考值调整为单手 6.5 次/秒、移动 7 场地半径/秒、打法偏好 -0.2；这只改变软评分，不能放宽占手与原生判定。硬抗、分页、拆谱是独立可选的参数预设，手动调整变为自定义。
- 默认搜索预算 3 亿工作单位；可选 5000 万、6 亿以及最高 10 亿的自定义值。超预算窗口按基础排布补色时明确标为“未验证”，高置信模式不应用这些补色。
