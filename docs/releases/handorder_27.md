# MiaCode HandOrder 2.0.1-handorder.27

基于 MiaCode dev 固定基线 `be494a567869b407fd17acad33482af6ad1c664d`。

保留人工手序标注与分色，并同步 Better 的工作区、时间轴、Drop、压力与导出增强。

## 公开版功能

- 在谱面源码中人工标注 `~l`（左手）、`~r`（右手）、`~m`（任选一只手）；`~m` 不表示两手同时使用。
- 批量给完整选中音符赋手别；拆分星星轨迹的手序区间，并编辑换手节点。Wifi 支持双扇区和显式单手模式。
- 预览、时间轴及视频导出显示手序颜色；视频与预览底部显示扩展署名和版本号。
- 便携包使用独立的配置、缓存、会话和日志目录，不读取或迁移官方版个人数据。

实验性的自动手序拆解不包含在此公开版本中。手序是作者的人工标注，观看者仍需自行判断打法。

## 编辑与导出功能

- 源码、时间轴和预览同步音符选择，支持 Shift 框选、非连续对象编辑，以及独立选择 Slide 头星和轨迹。
- 时间轴支持连续缩放、独立调整音符大小、四种键位排列及横向、上落、下落布局。默认时间轴、语法、无理共用下方标签栏，各面板可独立停靠或浮动。
- 左侧活动栏固定，大纲可独立停靠或浮动。“工作区”菜单管理面板显隐、预览侧、侧栏样式、时间轴布局和命名布局。按反引号最大化或恢复当前面板。
- 高级谱面信息可填写歌曲、谱师、版本、定数、试听区间和作者备注。
- 自动推荐 Drop 区间，支持手动调整、选区右键设置或取消，并保存至 maidata；预览与视频导出可直接采用。
- 压力热图综合位移、动作上下文和耐力负荷，留白压力为零，悬停仍可查看疲劳恢复和人工标注的左右手信息。点击或拖动可定位。
- 常规预览始终隐藏判定标记和触摸轨迹；无理和黑底调试保留各自开关。小节线、判定骨骼和 Slide 判定时值统一在显示菜单设置。BPM、CPS 等信息支持自由比例画面。
- 视频支持谱面预览片头、同步导出多张封面、30／100／200 MB 体积预设和自定义码率，PV 可独立开关。
- 视频模板支持保存、应用与导入导出，使用 `.miatemplate` 后缀并兼容旧 JSON 文件；封面文字支持描边和阴影。
- 支持 BPM 导入、应用与导出，以及 DX 失分和 SSS／SSS+ 容错计算。
- 支持自动整理与原文件备份、空格防误触、空难度打包提醒和低性能模式。
- 🦊狐狸在 Drop 段闭眼跟拍跳跃，其余段落轻摇头、摆尾并自然眨眼。

## 快捷键

先聚焦谱面源码并选中完整音符；可在首选项中重绑。保留左手的默认绑定时，Alt+W 在源码有可编辑选区时优先标左手，其余位置可打开“工作区”菜单。

| 功能 | 默认快捷键 |
| --- | --- |
| 左手 | Alt+W |
| 右手 | Alt+E |
| 拆分星星手序区间 | Alt+T |
| 左右手均可 | Alt+Y |
| 拆成独立 slide | Ctrl+Alt+5 |

“拆分星星手序区间”只修改标注。“拆成独立 slide”会改变原生谱面对象，可能影响判定、物量和计分，请先查看应用前的差异预览。

## 安装与版本范围

- 本次准备 Windows x64 Release 包；其他平台未在本次本机验证。
- 完整解压后从根目录 `MiaCode.exe` 启动，更新时保留本产品独立的 `runtime/`。
- 谱库管理仅进入下一版规划，本版不包含谱库扫描或迁移。
