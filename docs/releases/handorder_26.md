# MiaCode Hand Order 2.0.1-handorder.26 · 手序功能 V26

基于 Team-MiaCode MiaCode 2.0.1 的公开人工手序扩展，由 @albertoBradish 开发。此包只含人工标注、编辑和渲染；自动手序、交互自动拆解、共同轴拆解及候选识别实验均不进入公开版本。

## 本次 V26 更新

- 预览、时间轴支持 Shift + 单击或拖框选择/反选完整音符，Ctrl/Command 不再加选；时间轴增加拖框轮廓和安全取消机制。
- 修复框选后的快捷处理。选中对象可以直接设手、交换左右、二分轨迹、复制、剪切、删除及执行编辑变换。非连续选点不会误改中间未选音符，每次批处理可一次撤销。
- 视频底部署名显示独立的手序功能版本 V26，保留 50% 不透明度。
- 视频导出新增显示项默认折叠在“更多显示”，折叠不会改变原有选项值。

## 相对上游稳定版的完整手序功能

- 原生 Simai 上的人工标注：`~l` 左手蓝色、`~r` 右手红色、`~m` 任选灰白色。批量设手，星星轨迹多区间换手、链式/分支 Slide 与 Wifi 双扇区或显式单手均可编辑。
- Alt+W / Alt+E / Alt+Y 设左手、右手或任选；Alt+T 编辑拆分区间；Alt+C 对光标所在或选中的 Slide 二分并保留既有手别；Alt+Q 交换左右。快捷键可在首选项重绑。
- Ctrl+Alt+5 提供原生 Slide 独立拆分和差异确认；该操作会改变原生对象，可能影响判定及计分。需要连续上下文的区间编辑和原生拆分会对非连续对象集合给出明确提示。
- 手序颜色用于原生皮肤、时间轴、预览和视频导出，预览与导出共用场景；原谱模式和纯 Simai 导出可忽略或去除扩展标注。无效标注独立报告，不改变原谱时间和几何。
- 行号点击暂停定位、按独立音符范围描边、播放选区并保留进场和完整尾部、小节线及判定骨骼。选区描边只用于编辑，不写入导出。
- 集成 Slide 判定时值、启动拍及“启动拍前已进入 Perfect 时，从头拍全亮”显示；默认关闭，保留手序染色、换手、Wifi 裁剪和当前判定模式的消轨语义。
- 独立应用身份、根目录启动器和包内 runtime，隔离配置、缓存、会话、恢复、日志及 worker；不迁移正式版数据，不通过官方更新服务覆盖安装。默认音频通道为完整音量。

## 包与验证

提供 Windows x64 Release 归档及 SHA-256，完整解压后从根目录 `MiaCode.exe` 启动，保留 `app/`、`assets/` 和包标记。发布附件附自动验证报告；本轮聚焦检查只使用合成谱面，覆盖对象编辑、预览与时间轴真实窗口手势、显示折叠和运行隔离。主 GUI 人工验收及其他平台不在本次 Windows 包的验证范围内。
