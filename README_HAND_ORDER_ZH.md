# MiaCode HandOrder 2.0.1-handorder.26（Windows x64）

本包由 @albertoBradish 基于 Team-MiaCode 的 MiaCode v2.0.1 开发，不是官方 MiaCode 发行版。完整解压到可写目录，从包根目录的 `MiaCode.exe` 启动。请保留 `app/`、`assets/` 与 `HandOrderPackage.marker`。

公开版提供人工手序标注：`~l` 为左手蓝色、`~r` 为右手红色、`~m` 为左右任选的灰白色。可以对完整选区批量赋值，也可以拆分星星轨迹的标注区间并编辑换手。Wifi 支持双扇区和显式单手模式。预览、时间轴和视频导出可以显示手序颜色；预览与视频底部显示扩展署名和版本号。实验性的自动手序拆解不在此包中。

| 功能 | 默认快捷键 |
| --- | --- |
| 左手 | Alt+W |
| 右手 | Alt+E |
| 拆分星星手序区间 | Alt+T |
| 一键拆分 | Alt+C |
| 交换左右手 | Alt+Q |
| 左右手均可 | Alt+Y |
| 拆成独立 slide | Ctrl+Alt+5 |

可在谱面源码中选中完整音符，或在预览和时间轴中按住 Shift 单击/拖框进行选择与反选；Ctrl/Command 不再加选。框选后可直接使用编辑快捷键。可在首选项里重绑快捷键。“拆成独立 slide”会改变原生对象，可能影响判定和计分；应用前先检查差异预览。

配置、缓存、会话和日志保存在本包 `runtime/`，默认导出保存在 `exports/`。此包不读取或迁移正式版的偏好、自动恢复和最近文件。请勿只复制 `app/MiaCode.exe` 运行。

“一键拆分”可处理光标所在的当前 Slide 或选中 Slide，首次将轨迹均分为左右两段，重复执行继续细分并保留已有手别；“交换左右手”交换选区中的人工标注，保留轨迹进度和原生谱面。底部署名为“由@albertoBradish 开发的Miacode手序拓展拆解并渲染，V26（手序功能版本）”，不透明度为 50%。

本轮集成 Better Miacode 的行号点击暂停定位、小节线、选区细描边、播放选区和判定骨骼。画面辅助可在预览和导出中设置，选区描边只用于编辑。小节线支持谱面 clock_count、自定义拍数及文本行首；播放选区保留音符进场和完整尾部。

本包附带合成谱面的[人工验收清单](acceptance/MANUAL_CHECKLIST_ZH.md)。未勾选项目仍待人工确认；Windows 可执行文件未签名。


## Slide 判定时值（Better.8）

预览画面选项和视频导出均支持“显示 Slide 判定时值”，默认关闭。从原 star 头拍沿路径匀速将低亮轨迹恢复为正常亮度，在最早 Perfect 时刻全亮，轨迹仍按当前判定模式消失。

可选“有启动拍时从启动拍开始”。同一时刻、同一起点的 star、tap、hold 头和 A 区 touch 可作为启动拍，没有匹配时回退到原头拍。子选项“启动拍前已进入 Perfect 时，从头拍全亮”开启后，符合条件的 slide 跳过补间，从原头拍全亮。三个开关均默认关闭。

手序染色、换手节点、WiFi 双扇区裁剪与透明度保持原语义；补间与手序着色共同作用。完整规则见包内 `docs/specs/preview/SLIDE_JUDGEMENT_TIMING_ZH.md`。

视频导出的新增画面辅助选项默认折叠到“更多显示”；展开与收起均保留原有设置。
