# MiaCode HandOrder 2.0.0-alpha（Windows x64）

将整个压缩包解压到**可写目录**，双击根目录的 `MiaCode.exe` 启动。请保留 `app/`、`assets/` 和 `HandOrderPackage.marker`；只复制 exe 无法运行。

本版本支持 `~l`（左手蓝）、`~r`（右手红）、`~m`（左右任选灰白）的手序标注。内置 SD/DX 皮肤使用从原美术生成的染色素材。未标注的音符及关闭手序显示后的画面使用原皮肤；视频导出可选择跟随预览、原谱或手序模式。

配置、缓存、会话、日志保存在解压目录的 `runtime/`，默认导出目录为 `exports/`。它不读取或迁移正式版 MiaCode 的偏好、自动恢复内容和谱面。将整个解压目录移走时，这些数据也会一同移动；建议自行备份在此版本创建的谱面。

本包仍为 alpha。合成谱面的解析、换手预览和视频导出已验证；GUI 操作、真实谱面批量导出和跨平台行为尚未完成验收。Windows 可执行文件未附代码签名。
